# 🎓 Career Guidance

A simple and helpful web platform that guides students to choose the right stream, course or career after 10th, 12th or graduation.

🔗 **Live Demo:** [career-guidance-steel.vercel.app](https://career-guidance-steel.vercel.app/)

## ✨ Features

* 🧭 **Guidance at Every Stage** — Options for after 10th, after 12th and after graduation
* 🎯 **Interest-Based Suggestions** — Answer a few questions and get a path that fits your interests
* ✅ **Task-Based Roadmap** — Follow a step-by-step plan for your chosen path
* 🏆 **Certificate on Completion** — Finish your roadmap and earn a certificate
* 📱 **Responsive Design** — Works smoothly across devices

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Node.js
* MongoDB
* Vercel (Deployment)

## 🚀 Getting Started

1. Clone the repository

```
git clone https://github.com/your-username/career-guidance.git
```

2. Install dependencies

```
cd career-guidance
npm install
```

3. Create a `.env` file and add your values

```
MONGODB_URI=your_mongodb_connection_string
PORT=3000
```

4. Start the server

```
npm start
```

5. Open `http://localhost:3000` in your browser
